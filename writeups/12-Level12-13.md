# Bandit Level 12 → 13

## Objective

Retrieve the password for Bandit Level 13 by extracting and decoding a file that has been compressed and encoded multiple times.

---

## Challenge Description

The password for the next level is stored in `data.txt`, which contains a hexadecimal dump of a file. After reconstructing the original file, multiple layers of compression and encoding must be identified and extracted until the plaintext password is revealed.

---

## Enumeration

The challenge began with a hexadecimal dump rather than a normal file. After recreating the binary file, I repeatedly identified its file type using the `file` command. Depending on the detected format, I used the appropriate extraction or decompression utility. This process continued until the original text file containing the password was recovered.

---

## Commands Used

```bash
mkdir /tmp/bandit12

cp data.txt /tmp/bandit12

cd /tmp/bandit12

xxd -r data.txt > data

file data

mv data data.gz
gunzip data.gz

file data

mv data data.bz2
bunzip2 data.bz2

file data

mv data data.gz
gunzip data.gz

file data

tar -xf data

file data5.bin

mv data5.bin data.tar
tar -xf data.tar

file data6.bin

mv data6.bin data.bz2
bunzip2 data.bz2

file data6

mv data6 data.tar
tar -xf data.tar

file data8.bin

mv data8.bin data.gz
gunzip data.gz

cat data8
```

> **Note:** The exact filenames (`data5.bin`, `data6.bin`, etc.) may vary depending on how you extract the archive. The important part is identifying each file type using the `file` command before choosing the next tool.

---

## Explanation

- Created a temporary working directory to avoid modifying the original challenge files.
- Reconstructed the original binary file from its hexadecimal dump using `xxd -r`.
- Used the `file` command after each extraction step to determine the current file format.
- Applied the correct decompression or extraction utility (`gunzip`, `bunzip2`, `tar`) based on the detected format.
- Repeated the process until the final plaintext file containing the password was obtained.

## Commands Learned

| Command | Purpose |
|---------|----------|
| `xxd -r` | Reconstruct a binary file from a hexadecimal dump |
| `file` | Identify the actual type of a file |
| `gunzip` | Decompress Gzip files |
| `bunzip2` | Decompress Bzip2 files |
| `tar -xf` | Extract files from a TAR archive |
| `cp` | Copy files |
| `mkdir` | Create a new directory |

---

## Key Learning

- Always identify a file before attempting to extract it.
- Complex files may contain multiple layers of compression or encoding.
- Following a structured, step-by-step approach is more reliable than guessing file formats.

---

## Real-World Application

Digital forensics, malware analysis, and incident response often involve recovering data from archives, memory dumps, or encoded payloads. Analysts frequently encounter files that have been compressed or encoded multiple times to reduce size or evade detection. Using tools like `file`, `xxd`, `gunzip`, `bunzip2`, and `tar` helps safely identify and recover the original data.
