# Bandit Level 24 → 25

## Objective

Retrieve the password for Bandit Level 25 by brute-forcing a 4-digit PIN against a network service.

---

## Challenge Description

A daemon is listening on `localhost` port `30002`. The service requires the current level's password followed by a four-digit PIN. The objective is to determine the correct PIN and obtain the password for the next level.

---

## Enumeration

The challenge specified that the PIN consisted of exactly four digits, resulting in 10,000 possible combinations (`0000`–`9999`). Rather than testing each PIN manually, I automated the process by generating every possible combination and sending each attempt to the service using `netcat`.

---

## Commands Used

Generate all PIN combinations and send them to the service:

```bash
for i in $(seq 0 9999)
do
    printf "%s %04d\n" "$(cat /etc/bandit_pass/bandit24)" "$i"
done | nc localhost 30002
```

---

## Explanation

- Retrieved the current level's password.
- Generated every possible four-digit PIN using `seq`.
- Used `printf` with `%04d` to ensure leading zeros were included (e.g., `0007`).
- Sent each password-PIN pair to the service through a single `netcat` connection.
- Continued until the service accepted the correct PIN and returned the password for the next level.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `seq` | Generate a sequence of numbers |
| `printf` | Format and print output |
| `%04d` | Display a number using four digits with leading zeros |
| `nc` | Communicate with TCP services |
| `$(...)` | Perform command substitution |

---

## Key Learning

- Automation is essential when repetitive tasks involve many possibilities.
- Brute-force attacks become practical when the search space is small.
- Shell scripting can eliminate repetitive manual work and reduce human error.

---

## Real-World Application

Security professionals use automation to perform password audits, fuzz applications, test authentication mechanisms, and validate system behavior. While brute-force attacks can identify weak credentials or predictable authentication schemes, they should only be performed with proper authorization during security assessments.
