# Bandit Level 11 → 12

## Objective

Retrieve the password for Bandit Level 12 by decoding text encrypted using the ROT13 cipher.

---

## Challenge Description

The password for the next level is stored in the file `data.txt`, where all alphabetical characters have been encoded using the ROT13 substitution cipher. The goal is to decode the text and recover the original password.

---

## Enumeration

The challenge description identified the encoding method as ROT13. Instead of manually replacing each character, I used the `tr` command to translate each letter to its corresponding character in the ROT13 alphabet.

---

## Commands Used

```bash
cat data.txt | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

Alternative:

```bash
tr 'A-Za-z' 'N-ZA-Mn-za-m' < data.txt
```

---

## Explanation

- Read the contents of `data.txt`.
- Used the `tr` command to translate each uppercase and lowercase letter according to the ROT13 substitution cipher.
- Displayed the decoded text, which contained the password for the next level.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `tr` | Translate or replace characters from one set to another |
| `cat` | Display the contents of a file |
| `<` | Redirect a file as input to a command |
| `|` (Pipe) | Pass the output of one command as the input to another |

---

## Key Learning

- ROT13 is a simple substitution cipher that rotates each letter by 13 positions.
- The `tr` command is useful for translating characters and performing simple text transformations.
- Understanding common encoding and substitution techniques helps during security investigations.

---

## Real-World Application

Although ROT13 is not considered secure encryption, simple substitution methods are still encountered in Capture The Flag (CTF) challenges, legacy applications, malware obfuscation, and log analysis. Security professionals should be able to quickly recognize and decode such transformations.
