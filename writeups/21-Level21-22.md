# Bandit Level 21 → 22

## Objective

Retrieve the password for Bandit Level 22 by analyzing a scheduled Cron job and locating the file it creates.

---

## Challenge Description

A program is executed automatically at regular intervals by the Linux Cron scheduler. The objective is to inspect the scheduled task, understand what it does, and locate the file containing the password for the next level.

---

## Enumeration

The challenge hinted that a Cron job was responsible for generating the password. I began by inspecting the system's Cron directories to identify the scheduled task. After locating the appropriate script, I analyzed its contents to determine where it stored the generated password.

---

## Commands Used

```bash
ls /etc/cron.d

cat /etc/cron.d/cronjob_bandit22

cat /usr/bin/cronjob_bandit22.sh

cat /tmp/<generated_filename>
```

> **Note:** Replace `<generated_filename>` with the filename determined from the script.

---

## Explanation

- Listed the Cron configuration files.
- Identified the job associated with `bandit22`.
- Examined the Cron configuration to determine which script was executed.
- Read the script to understand its behavior.
- Identified the output file created in `/tmp`.
- Retrieved the password from the generated file.

## Key Learning

- Cron is a task scheduler used to automate commands and scripts.
- Reading automation scripts is often more effective than guessing their behavior.
- Understanding how scheduled jobs work can reveal valuable system information.

---

## Real-World Application

Cron jobs are widely used to automate backups, log rotation, software updates, security scans, monitoring tasks, and maintenance scripts. During security assessments and incident response, analysts inspect scheduled tasks to identify persistence mechanisms, unauthorized scripts, or automated processes that may have been modified by an attacker.
