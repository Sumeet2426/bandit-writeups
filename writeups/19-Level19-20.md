# Bandit Level 19 → 20

## Objective

Retrieve the password for Bandit Level 20 by executing a privileged program.

---

## Challenge Description

A program named `bandit20-do` is available in the home directory. This program executes commands with the privileges of the `bandit20` user. The objective is to use this program to access the password for the next level.

---

## Enumeration

After listing the contents of the home directory, I found the executable `bandit20-do`. Since its purpose was described in the challenge, I first viewed its usage information before executing the required command.

---

## Commands Used

```bash
ls -l

./bandit20-do

./bandit20-do cat /etc/bandit_pass/bandit20
```

---

## Explanation

- Listed the files in the current directory.
- Identified the `bandit20-do` executable.
- Executed the program without arguments to understand its usage.
- Used the program to run the `cat` command with the privileges of the `bandit20` user.
- Retrieved the password stored in `/etc/bandit_pass/bandit20`.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `ls -l` | Display detailed file information and permissions |
| `./program` | Execute a program located in the current directory |
| `cat` | Display the contents of a file |

---

## Key Learning

- Some programs are designed to execute commands with elevated privileges.
- Understanding how privileged executables work is important for both system administration and security.
- Always inspect a program's intended behavior before using it.

---

## Real-World Application

Linux systems often use controlled privilege escalation mechanisms such as `sudo` or specialized helper programs to allow users to perform administrative tasks without granting unrestricted root access. Security professionals analyze privileged executables to ensure they cannot be abused for unauthorized access.
