# Bandit Level 26 → 27

## Objective

Retrieve the password for Bandit Level 27 by using a SUID program that executes commands with another user's privileges.

---

## Challenge Description

After gaining access to the `bandit26` account, the objective is to retrieve the password for `bandit27`. A SUID executable named `bandit27-do` is available, allowing specific commands to be executed with the privileges of the `bandit27` user.

---

## Enumeration

After escaping the restricted shell from the previous level, I listed the contents of the home directory and identified the executable `bandit27-do`. Running the program without arguments displayed its usage information, indicating that it could execute commands as the `bandit27` user.

---

## Commands Used

List the available files:

```bash
ls -la
```

Check the program usage:

```bash
./bandit27-do
```

Retrieve the password:

```bash
./bandit27-do cat /etc/bandit_pass/bandit27
```

---

## Explanation

- Listed the files in the current directory.
- Identified the privileged executable `bandit27-do`.
- Executed the program without arguments to understand its purpose.
- Used the program to execute the `cat` command with the privileges of the `bandit27` user.
- Retrieved the password stored in `/etc/bandit_pass/bandit27`.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `ls -la` | Display detailed information about all files, including hidden files |
| `./program` | Execute a program in the current directory |
| `cat` | Display the contents of a file |

---

## Key Learning

- SUID programs execute with the permissions of their owner rather than the user running them.
- Privileged executables should expose only the functionality necessary to perform authorized tasks.
- Understanding how privileged programs work is essential when assessing Linux system security.

---

## Real-World Application

SUID programs are commonly used on Linux systems to allow users to perform specific privileged operations without granting full administrative access. Security professionals regularly audit SUID binaries because improperly designed or misconfigured programs can introduce privilege escalation vulnerabilities.
