# Bandit Level 18 → 19

## Objective

Retrieve the password for Bandit Level 19 despite the default shell immediately logging out upon login.

---

## Challenge Description

The password for the next level is stored in the `readme` file in the home directory. However, the login shell has been modified to immediately terminate the session, preventing normal interactive access.

---

## Enumeration

Attempting to log in normally resulted in an immediate logout. Since the shell was terminating after login, I needed a way to execute a command before the shell exited. SSH allows commands to be executed directly during connection, bypassing the need for an interactive shell.

---

## Commands Used

```bash
ssh bandit18@bandit.labs.overthewire.org -p 2220 "cat readme"
```

---

## Explanation

- Attempted a normal SSH login but the session terminated immediately.
- Recognized that interactive access was restricted.
- Used SSH's remote command execution feature to run `cat readme` directly.
- Retrieved the password without opening an interactive shell.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `ssh user@host "command"` | Execute a command on a remote system without starting an interactive shell |
| `cat` | Display the contents of a file |

---

## Key Learning

- SSH is capable of executing remote commands directly.
- Interactive shell access is not always required to perform administrative tasks.
- Understanding alternative ways to interact with remote systems is valuable when restrictions are present.

---

## Real-World Application

System administrators frequently use SSH to execute remote commands for automation, backups, monitoring, and configuration management. During penetration testing and incident response, direct command execution can also be useful when interactive shell access is restricted or intentionally disabled.
