# Bandit Level 32 → 33

## Objective

Retrieve the password for Bandit Level 33 by escaping a shell that automatically converts commands to uppercase.

---

## Challenge Description

After logging in, every command entered into the shell is automatically converted to uppercase, causing normal Linux commands to fail. The objective is to understand the shell's behavior and find a method to execute commands without being affected by the uppercase conversion.

---

## Enumeration

Normal commands such as `ls`, `pwd`, and `cat` were automatically converted to uppercase (`LS`, `PWD`, `CAT`), which do not exist as valid Linux commands. Instead of searching for another executable, I investigated how the shell processed input and discovered that shell variables are expanded before the uppercase conversion occurs.

---

## Commands Used

Start the default shell:

```bash
$0
```

Verify the current user:

```bash
whoami
```

Retrieve the password:

```bash
cat /etc/bandit_pass/bandit33
```

---

## Explanation

- Observed that normal commands failed because they were converted to uppercase.
- Used the special shell variable `$0`, which expands to the name of the current shell executable.
- The shell expanded `$0` before applying the uppercase transformation.
- This launched a normal shell where standard Linux commands worked as expected.
- Read the password for the next level.

---

## Key Learning

- Shells perform parameter expansion before executing commands.
- Understanding shell behavior is often more valuable than memorizing commands.
- Special shell variables can sometimes be used to bypass restricted environments.

---

## Real-World Application

Restricted shells are commonly used to limit user actions on servers and embedded systems. Security professionals assess these environments to determine whether shell features, environment variables, or built-in functionality allow users to escape the restrictions. Many historical privilege escalation techniques have relied on understanding shell behavior rather than exploiting software vulnerabilities.
