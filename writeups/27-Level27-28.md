# Bandit Level 27 → 28

## Objective

Retrieve the password for Bandit Level 28 by cloning a remote Git repository and examining its contents.

---

## Challenge Description

The password for the next level is stored inside a Git repository hosted on the Bandit server. The objective is to authenticate using SSH, clone the repository, and inspect its files.

---

## Enumeration

The challenge provided the repository location but not its contents. I created a temporary working directory and cloned the repository using Git over SSH. After cloning, I inspected the repository to identify files containing useful information.

---

## Commands Used

Create a temporary working directory:

```bash
mkdir /tmp/bandit27

cd /tmp/bandit27
```

Clone the repository:

```bash
GIT_SSH_COMMAND="ssh -p 2220" git clone ssh://bandit27-git@bandit.labs.overthewire.org/home/bandit27-git/repo
```

Navigate into the repository:

```bash
cd repo

ls -la

cat README
```

---

## Explanation

- Created a temporary directory to avoid modifying existing files.
- Cloned the remote Git repository using SSH authentication.
- Entered the cloned repository.
- Listed the repository contents.
- Opened the `README` file, which contained the password for the next level.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `git clone` | Download a remote Git repository |
| `GIT_SSH_COMMAND` | Specify a custom SSH command for Git |
| `cd` | Change the current working directory |
| `ls -la` | Display all files, including hidden files |
| `cat` | Display the contents of a file |

---

## Key Learning

- Git repositories can be accessed securely over SSH.
- Cloning creates a complete local copy of a repository, including its history.
- Version control systems are valuable sources of information during security assessments.

---

## Real-World Application

Git is the standard version control system used in software development and DevSecOps. Security professionals frequently clone repositories to perform source code reviews, analyze infrastructure-as-code, investigate exposed secrets, and audit application changes. Understanding Git is essential for secure software development and modern cybersecurity workflows.
