# Bandit Level 14 → 15

## Objective

Retrieve the password for Bandit Level 15 by sending the current level's password to a service listening on port **30000** using a TCP connection.

---

## Challenge Description

The password for the next level can be obtained by connecting to a service running on `localhost` at port `30000`. The service expects the current level's password as input and returns the password for the next level upon successful authentication.

---

## Enumeration

The challenge description specified that a service was listening on a local TCP port. Since no encryption or special protocol was mentioned, I used `netcat (nc)` to establish a TCP connection and communicate with the service.

---

## Commands Used

```bash
cat /etc/bandit_pass/bandit14

nc localhost 30000
```

Then entered:

```text
<bandit14_password>
```

Alternatively:

```bash
cat /etc/bandit_pass/bandit14 | nc localhost 30000
```

---

## Explanation

- Retrieved the current level's password.
- Connected to the TCP service running on `localhost` at port `30000` using `nc`.
- Sent the password to the service.
- The service verified the password and returned the password for Bandit Level 15.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `nc` | Create TCP or UDP connections to network services |
| `localhost` | Refers to the local machine (127.0.0.1) |
| `cat` | Display the contents of a file |
| `|` (Pipe) | Send the output of one command as input to another |

---

## Key Learning

- Services often communicate over TCP ports.
- `netcat` is a simple but powerful tool for interacting with network services.
- Command pipelines can automate communication between commands and network services.

---

## Real-World Application

`Netcat` is widely used by penetration testers, SOC analysts, and system administrators to test network connectivity, interact with services, transfer data, perform banner grabbing, and troubleshoot applications. Understanding how to manually communicate with TCP services is an essential networking skill.
