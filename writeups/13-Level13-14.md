# Bandit Level 13 → 14

## Objective

Retrieve the password for Bandit Level 14 by authenticating with an SSH private key instead of a password.

---

## Challenge Description

The password for the next level is not stored in a file. Instead, a private SSH key (`sshkey.private`) is provided. This key must be used to log in as the `bandit14` user and retrieve the password from the appropriate password file.

---

## Enumeration

After listing the files in the home directory, I found a private SSH key named `sshkey.private`. Since SSH supports key-based authentication, I used this key to connect to the Bandit server as the `bandit14` user.

---

## Commands Used

```bash
ls

chmod 600 sshkey.private

ssh -i sshkey.private bandit14@localhost -p 2220

cat /etc/bandit_pass/bandit14
```

---

## Explanation

- Listed the files in the current directory.
- Identified the private SSH key (`sshkey.private`).
- Restricted the file permissions using `chmod 600`, ensuring only the owner could read and write the key.
- Used the `-i` option with `ssh` to specify the private key for authentication.
- Logged in successfully as `bandit14`.
- Retrieved the password from `/etc/bandit_pass/bandit14`.

## Commands Learned

| Command | Purpose |
|---------|----------|
| `chmod 600` | Restrict file permissions so only the owner can read and write |
| `ssh -i` | Authenticate using a specified private SSH key |
| `cat` | Display the contents of a file |
| `ls` | List files and directories |

---

## Key Learning

- SSH supports password-based and key-based authentication.
- Private keys should have restrictive permissions to prevent unauthorized access.
- Key-based authentication is more secure than password authentication and is widely used in production environments.

---

## Real-World Application

Organizations commonly disable password-based SSH logins and require key-based authentication for improved security. Cloud platforms such as AWS, Azure, and Google Cloud use SSH key pairs to securely access Linux virtual machines. Understanding SSH keys is essential for system administration, DevOps, and cybersecurity roles.
