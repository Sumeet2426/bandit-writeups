# Bandit Level 15 → 16

## Objective

Retrieve the password for Bandit Level 16 by securely communicating with a service using SSL/TLS.

---

## Challenge Description

The password for the next level can be obtained by connecting to a service running on `localhost` at port `30001`. Unlike the previous level, this service requires an encrypted SSL/TLS connection. After establishing the connection, the current level's password must be submitted to receive the next password.

---

## Enumeration

The challenge description indicated that the service required SSL/TLS encryption. Since `netcat` does not establish encrypted connections, I used the `openssl s_client` utility to create a secure connection before sending the password.

---

## Commands Used

```bash
cat /etc/bandit_pass/bandit15

openssl s_client -connect localhost:30001
```

Then entered:

```text
<bandit15_password>
```

Alternatively:

```bash
cat /etc/bandit_pass/bandit15 | openssl s_client -connect localhost:30001 -quiet
```

---

## Explanation

- Retrieved the current level's password.
- Established an encrypted SSL/TLS connection to the service using `openssl s_client`.
- Submitted the password through the secure connection.
- The server verified the password and returned the password for Bandit Level 16.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `openssl s_client` | Connect to a server using SSL/TLS |
| `-connect` | Specify the destination host and port |
| `-quiet` | Suppress certificate and connection details |
| `cat` | Display the contents of a file |
| `|` (Pipe) | Send the output of one command as input to another |

---

## Key Learning

- Some network services require encrypted communication using SSL/TLS.
- `openssl s_client` can be used to manually test and interact with secure services.
- Choosing the correct tool depends on the protocol used by the service.

---

## Real-World Application

Security professionals use `openssl s_client` to troubleshoot HTTPS services, inspect SSL/TLS certificates, verify encryption settings, test secure mail servers, and diagnose certificate-related issues. It is an essential tool for validating secure network communications.
