# Bandit Level 10 → 11

## Objective

Retrieve the password for Bandit Level 11 by decoding the contents of a Base64 encoded file.

---

## Challenge Description

The password for the next level is stored in the file `data.txt`, which contains data encoded using the Base64 encoding scheme. The objective is to decode the file and retrieve the original plaintext password.

---

## Enumeration

After reading the challenge description, it was clear that the file was Base64 encoded. Since Base64 is an encoding method rather than encryption, I used the appropriate Linux utility to decode the contents.

---

## Commands Used

```bash
base64 -d data.txt
```

Alternative:

```bash
cat data.txt | base64 -d
```

---

## Explanation

- Identified that the contents of `data.txt` were Base64 encoded.
- Used the `base64` utility with the `-d` option to decode the file.
- Displayed the decoded plaintext, which contained the password for the next level.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `base64` | Encode or decode data using the Base64 format |
| `-d` | Decode Base64 encoded data |
| `cat` | Display the contents of a file |
| `|` (Pipe) | Pass the output of one command to another |

---

## Key Learning

- Base64 is an encoding technique, not an encryption method.
- Encoded data can be easily converted back to its original form without requiring a key.
- Recognizing common encoding formats is an important skill during security assessments and investigations.

---

## Real-World Application

Base64 is commonly used to encode email attachments (MIME), JSON Web Tokens (JWTs), API requests, HTTP Basic Authentication credentials, and malware payloads. Cybersecurity professionals frequently decode Base64 data while analyzing logs, inspecting web traffic, performing malware analysis, and investigating suspicious scripts.
