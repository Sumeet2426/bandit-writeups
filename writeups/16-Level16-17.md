# Bandit Level 16 → 17

## Objective

Retrieve the credentials required for Bandit Level 17 by identifying the correct SSL/TLS service among multiple open ports.

---

## Challenge Description

A service is listening on one of the TCP ports between **31000** and **32000**. Some ports use plain TCP, while others use SSL/TLS. The objective is to identify the correct SSL-enabled service, authenticate with the current level's password, and obtain the SSH private key for the next level.

---

## Enumeration

Since the exact port was unknown, I first scanned the specified port range using `nmap` to identify open ports. After discovering the available services, I used `openssl s_client` to determine which port accepted SSL/TLS connections. Once the correct service was found, I submitted the current level's password and received the SSH private key.

---

## Commands Used

```bash
nmap -p 31000-32000 localhost
```

```bash
openssl s_client -connect localhost:<PORT> -quiet
```

Then entered:

```text
<bandit16_password>
```

After identifying the correct service:

```bash
cat > sshkey.private
```

Paste the private key, then press:

```text
CTRL + D
```

Restrict permissions:

```bash
chmod 600 sshkey.private
```

Authenticate as Bandit17:

```bash
ssh -i sshkey.private bandit17@localhost -p 2220
```

---

## Explanation

- Scanned the target port range using `nmap`.
- Identified which ports were open.
- Tested the open ports with `openssl s_client` to determine which supported SSL/TLS.
- Submitted the current password to the correct service.
- Received an SSH private key.
- Saved the key locally with secure permissions.
- Used the key to authenticate as the next user.

## Commands Learned

| Command | Purpose |
|---------|----------|
| `nmap` | Discover hosts and scan open ports |
| `-p` | Specify the port or port range to scan |
| `openssl s_client` | Connect to SSL/TLS services |
| `chmod 600` | Restrict access to a private key |
| `ssh -i` | Authenticate using a private SSH key |

---

## Key Learning

- Enumeration should always precede exploitation.
- Port scanning helps identify available services.
- Not every open port runs the same protocol.
- Testing services individually helps determine how they communicate.

---

## Real-World Application

Network enumeration is one of the first steps during penetration testing, vulnerability assessments, and incident response. Tools such as `nmap` are used to discover exposed services, while `openssl s_client` helps validate encrypted services and inspect their behavior. This systematic approach allows security professionals to understand the attack surface before interacting with systems.
