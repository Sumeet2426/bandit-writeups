# Bandit Level 17 → 18

## Objective

Retrieve the password for Bandit Level 18 by identifying the difference between two files.

---

## Challenge Description

The password for the next level is stored in the file `passwords.new`. It is the only line that differs from the corresponding line in `passwords.old`. The goal is to compare the two files and identify the changed password.

---

## Enumeration

After logging in as the `bandit17` user, I found two files: `passwords.old` and `passwords.new`. Since the challenge required finding the difference between them, I used the `diff` utility to compare both files.

---

## Commands Used

```bash
ls

diff passwords.old passwords.new
```

---

## Explanation

- Listed the files in the current directory.
- Identified the two password files.
- Used the `diff` command to compare them line by line.
- Located the single line that differed.
- The new line contained the password for Bandit Level 18.

---

## Commands Learned

| Command | Purpose |
|---------|----------|
| `diff` | Compare two files line by line |
| `ls` | List files and directories |

---

## Key Learning

- The `diff` command quickly identifies differences between two files.
- Comparing files is far more efficient than manually inspecting large datasets.
- Linux provides specialized tools for common administrative and investigative tasks.

---

## Real-World Application

The `diff` utility is widely used by system administrators and security professionals to compare configuration files, detect unauthorized changes, review software updates, analyze log differences, and verify system integrity. It is also the foundation of version control systems such as Git.
